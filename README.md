## 🌌 Concepto y Filosofía
Inspirado en la confluencia entre la estética de los neobancos más exclusivos del mundo (*Revolut Ultra*, *Apple Card Titanium*, *Linear*) y la economía de tiempo de la película *In Time*, **CHRONOS** redefine el dinero:

- **No gastes dinero, invierte vida:** Tu saldo principal se visualiza en años, días, horas, minutos y milisegundos reales.
- **Reloj Vital Ticking:** Un motor en vivo calcula el gasto biológico en milisegundos y los rendimientos pasivos de longevidad.
- **Tarjeta Chronos Titanium:** Tarjeta física y digital con efecto 3D que responde a la posición del cursor, con chip cuántico, bloqueo instantáneo y CVV dinámico.
- **Mercado de Tiempo (Swap):** Convierte USD, EUR o BTC en horas de vida instantáneas.
- **Cámaras Criogénicas (Staking):** Bloquea tiempo para obtener rendimientos anuales en horas y años garantizados.
- **T-Ledger Inmutable:** Registro criptográfico de cada segundo ganado, transferido o consumido.
- **Audio Háptico Cuántico:** Sintetizador Web Audio API puro, sin dependencias externas de archivos de audio.

## 🚀 Cómo Mirar la Página de Inmediato

### Opción 1: Abrir directamente en tu Navegador
Solo haz doble clic en `index.html` o arrástralo a Google Chrome, Microsoft Edge, Brave o Firefox. ¡Todo funciona sin requerir instalación previa ni compilación!

### Opción 2: Con servidor local rápido (Recomendado)
Abre PowerShell o terminal en esta carpeta y ejecuta:

```bash
# Con Python
python -m http.server 3000

# O con npx (Node.js)
npx serve
```
Luego visita: `http://localhost:3000`
